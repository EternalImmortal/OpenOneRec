# Assets 资源目录

该目录包含OpenOneRec项目相关的可视化资源和架构图表。

## 📁 目录内容

| 文件名 | 描述 | 用途 |
|--------|------|------|
| `main_framework.png` | OpenOneRec整体框架架构图 | 展示完整的训练流程和模块架构 |
| `framework.png` | 框架简化图 | 核心架构的简化展示 |
| `benchmark.png` | 基准测试性能对比图 | RecIF-Bench上的性能对比结果 |
| `onerec.png` | OneRec项目Logo | 项目标识 |

## 🖼️ 图表说明

### main_framework.png
- **位置**: 项目主README中引用
- **内容**: 展示OpenOneRec的完整技术架构
- **包含要素**:
  - Itemic Tokens机制
  - 两阶段预训练流程
  - 多任务SFT训练
  - 蒸馏和RL优化
  - RecIF-Bench评估框架

### benchmark.png
- **位置**: 项目主README和论文中引用
- **内容**: RecIF-Bench上的性能对比结果
- **展示指标**: Recall@32, AUC, LLM评分等
- **对比模型**: SASRec, TIGER, LC-Rec, OneRec系列模型

### framework.png
- **简化版架构图**
- 突出核心创新点：Items as Tokens

### onerec.png
- **项目品牌标识**
- 用于论文、文档和演示材料
